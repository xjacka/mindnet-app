Instalace na Android

  1. V telefonu otevři odkaz na APK a stáhni ho.
  2. Otevři stažený soubor. Android se zeptá, jestli smí prohlížeč instalovat aplikace — povol to (Instalovat neznámé aplikace).
  3. Google Play Protect může upozornit, že appku nezná: MindNet zatím není v Google Play. Zvol Další podrobnosti → Přesto nainstalovat.
  4. Přihlas se Googlem nebo e-mailem.

Když vyjde nová verze, appka to sama oznámí pruhem pod hlavičkou. Stačí klepnout na Stáhnout a nainstalovat ji přes starou — nic se neztratí.

Instalace rozšíření

Rozšíření zatím není v Chrome Web Storu, takže se instaluje z rozbalené složky:

  1. Stáhni zip s rozšířením a rozbal ho tam, kde může složka mindnet-extension natrvalo zůstat — prohlížeč ji čte z disku při každém spuštění. Složka Stažené soubory, kterou občas promazáváš, k tomu není dobrá.
  2. Otevři chrome://extensions a vpravo nahoře zapni Režim pro vývojáře.
  3. Klikni na Načíst rozbalené a vyber složku mindnet-extension.
  4. Připni si ikonu MindNetu vedle adresního řádku, otevři ji a přes ⚙ se přihlas — stejným účtem jako v appce.

Aktualizace: když je venku nová verze, ukáže se v okně rozšíření štítek Nová verze. Stáhni nový zip, rozbal ho přes starou složku a v chrome://extensions u MindNetu klikni na šipku pro obnovení. Přihlášení zůstane.

Vlastní agent

Články zpracovává jazykový model. Pokud máš vlastní předplatné — třeba Claude — může tvoje články zpracovávat tvůj vlastní agent: nečekáš na nikoho, nepočítá se ti to do denního stropu a model si vybereš sám.

Claude Code

  1. V appce otevři nastavení účtu → Vlastní agent a vytvoř klíč. Appka ti ukáže příkaz, který plugin MindNet nainstaluje rovnou s tím klíčem — vlož ho do terminálu.
  2. Nebo přímo v Claude Code: /plugin marketplace add xjacka/mindnet-app a /plugin install mindnet@mindnet-app. Když se na klíč nezeptá sám, zadáš ho příkazem /plugin configure mindnet@mindnet-app. Totéž udělá tlačítko Otevřít v Claude Code, když už Claude Code máš.
  3. Spusť /mindnet:setup. Ověří připojení a na přání nastaví pravidelné zpracování: v desktopové appce Claude jako naplánovanou úlohu, v terminálu jako /loop nebo úlohu na pozadí.
  4. V nastavení appky zvol, že tvoje články zpracovává vlastní agent.

Pravidelné běhy jedou jen na zapnutém počítači. Když agent neodpoví včas, článek zpracuje model, takže se nic nezasekne.

Jiný agent

Codex CLI, Cursor a další: přidej HTTP MCP server s adresou z appky a hlavičkou Authorization: Bearer mn_agent_… a dej agentovi skill process-mindnet-articles — popisuje, jak články vyzvedávat a odpovídat na zadání.

Agent přes MCP vidí jen tvoje články a zadání. Text článku tím odchází k poskytovateli tvého modelu.

Podmínky bety

  • MindNet je ve vývoji a zdarma. Funkce se mění, něco se může rozbít a beta může skončit.
  • Každý účet má denní strop zpracovaných článků; co se nevejde, zpracuje se další den.
  • Neposílej do MindNetu nic, co bys nesměl sdílet s poskytovateli služeb uvedenými v zásadách ochrany soukromí — text článků prochází jazykovým modelem.
  • Za obsah, který pošleš nebo sdílíš s ostatními, odpovídáš ty.
  • Účet i všechno, co v něm je, smažeš kdykoli v nastavení appky.
