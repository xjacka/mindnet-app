Installing on Android

  1. On your phone, open the APK link and download it.
  2. Open the downloaded file. Android asks whether your browser may install apps — allow it (Install unknown apps).
  3. Google Play Protect may warn that it does not know the app: MindNet is not on Google Play yet. Choose More details → Install anyway.
  4. Sign in with Google or with an email address.

When a new version comes out, the app tells you with a bar under its header. Tap Download and install it over the old one — nothing gets lost.

Installing the extension

The extension is not in the Chrome Web Store yet, so it is installed from an unpacked folder:

  1. Download the extension zip and unpack it somewhere the mindnet-extension folder can stay for good — the browser reads it from disk every time it starts. A Downloads folder you clean out now and then is not a good place.
  2. Open chrome://extensions and switch on Developer mode in the top right.
  3. Click Load unpacked and pick the mindnet-extension folder.
  4. Pin the MindNet icon next to the address bar, open it and sign in via ⚙ — with the same account as in the app.

Updates: when a new version is out, the extension window shows a New version label. Download the new zip, unpack it over the old folder and click the reload arrow next to MindNet in chrome://extensions. You stay signed in.

Own agent

Articles are processed by a language model. If you have your own subscription — Claude, for example — your own agent can process your articles: you wait for no one, it does not count towards your daily limit and you pick the model yourself.

Claude Code

  1. In the app, open account settings → Your own agent and create a key. The app shows a command that installs the MindNet plugin with that key — paste it into a terminal.
  2. Or right in Claude Code: /plugin marketplace add xjacka/mindnet-app and /plugin install mindnet@mindnet-app. If it does not ask for the key itself, enter it with /plugin configure mindnet@mindnet-app. The Open in Claude Code button does the same once you have Claude Code.
  3. Run /mindnet:setup. It checks the connection and, if you want, sets up regular processing: a scheduled task in the Claude desktop app, or /loop or a background job in a terminal.
  4. In the app's settings, choose that your articles are processed by your own agent.

Regular runs only run while your computer is on. When the agent does not answer in time, the model processes the article, so nothing gets stuck.

Another agent

Codex CLI, Cursor and others: add an HTTP MCP server with the address from the app and the header Authorization: Bearer mn_agent_…, and give the agent the skill process-mindnet-articles — it describes how to pick up articles and answer their prompts.

Over MCP the agent sees only your articles and prompts. The article text goes to your model's provider.

Beta terms

  • MindNet is under development and free. Features change, things may break and the beta may end.
  • Every account has a daily limit of processed articles; whatever does not fit is processed the next day.
  • Do not send MindNet anything you may not share with the service providers listed in the privacy policy — article text passes through a language model.
  • You are responsible for the content you send or share with others.
  • You can delete your account and everything in it at any time in the app's settings.
